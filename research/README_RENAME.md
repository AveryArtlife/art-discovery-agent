# Naming note

The research in this directory was performed under the working name **AminoLord / AminoLord.com**. After the research phase the concept was renamed **Reserve Clinic / ReserveClinic.com**. Research files are kept as written so that citations remain accurate. Consequences:

- Findings about the proposed principals, the market, competitors, celebrities and regulation are unaffected by the rename.
- Domain, trademark, entity and social-handle checks recorded for aminolord.com / AMINOLORD are historical. They must be re-run for reserveclinic.com / RESERVE CLINIC. On 2026-09-02, reserveclinic.com resolved to the same registrar parking addresses (3.33.130.190, 15.197.148.33), consistent with a registered but unlaunched domain (analyst inference; WHOIS blocked).
- "Reserve Clinic" adds a naming question for counsel: some states regulate use of "clinic" in the name of an entity not owned by licensed professionals, so the brand/MSO versus affiliated-practice use of the name must be confirmed.
